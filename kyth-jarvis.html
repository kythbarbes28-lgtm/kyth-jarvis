Google Drive

Create an OAuth Web Client ID in Google Cloud Console, enable the Drive API, and add this page’s origin (for example http://localhost:8000) under Authorized JavaScript origins. The app only requests the drive.file scope, so it can only touch the jarvis-data.json file it creates. It will not work from a file:// address.
